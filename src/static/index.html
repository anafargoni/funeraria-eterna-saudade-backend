Documentação da API do sistema.

Funerais

Rotas responsáveis pelo gerenciamento dos funerais.

GET /funeral
Listar funerais

Retorna todos os funerais cadastrados.

Parâmetros:

Não possui.

Exemplo de retorno:
[ { "id": 1, "duracao": 4, "data_evento": "2026-09-10", "local": "Cemitério Nossa Senhora do Carmo", "nome_falecido": "José da Silva", "data_nascimento_falecido": "1950-05-12", "data_morte_falecido": "2026-09-08", "cpf_falecido": "11122233344", "cpf_cliente": "12345678901", "pagamento": true } ]
GET /funeral/:id
Buscar funeral por ID

Retorna um funeral específico através do ID.

Parâmetro:
  • ID do funeral.
Restrições:
  • O ID deve ser um número inteiro maior que zero.
  • O funeral deve existir.
Exemplo de retorno:
{ "id": 1, "duracao": 4, "data_evento": "2026-09-10", "local": "Cemitério Nossa Senhora do Carmo", "nome_falecido": "José da Silva", "data_nascimento_falecido": "1950-05-12", "data_morte_falecido": "2026-09-08", "cpf_falecido": "11122233344", "cpf_cliente": "12345678901", "pagamento": true }
POST /funeral
Adicionar funeral

Cadastra um novo funeral e o associa a um cliente.

Campos obrigatórios:
  • duracao
  • data_evento
  • local
  • nome_falecido
  • data_nascimento_falecido
  • data_morte_falecido
  • cpf_falecido
  • cpf_cliente
  • pagamento
Restrições:
  • A duração deve ser maior que zero.
  • O CPF do falecido deve possuir 11 números.
  • O CPF do cliente deve possuir 11 números.
  • O cliente informado deve existir.
  • As datas devem ser iguais ou posteriores a 01/01/1900.
Exemplo de retorno:
{ "msg": "Funeral adicionado!", "data": { "id": 1, "duracao": 4, "data_evento": "2026-09-10", "local": "Cemitério Nossa Senhora do Carmo", "nome_falecido": "José da Silva", "data_nascimento_falecido": "1950-05-12", "data_morte_falecido": "2026-09-08", "cpf_falecido": "11122233344", "cpf_cliente": "12345678901", "pagamento": true } }

Restrições:

  • O CPF do falecido deve possuir 11 números.
  • O CPF do cliente deve possuir 11 números.
  • O cliente informado deve existir.
  • As datas devem ser iguais ou posteriores a 01/01/1900.
Exemplo de retorno:
{ "msg": "Funeral Atualizado!", "data": { "id": 1, "duracao": 4, "data_evento": "2026-09-10", "local": "Cemitério Nossa Senhora do Carmo", "nome_falecido": "José da Silva", "data_nascimento_falecido": "1950-05-12", "data_morte_falecido": "2026-09-08", "cpf_falecido": "11122233344", "cpf_cliente": "12345678901", "pagamento": true } }

Restrições:

Serviços

Rotas responsáveis pelo gerenciamento dos serviços.

GET /servico
Listar serviços

Retorna todos os serviços cadastrados.

Parâmetros:

Não possui.

Exemplo de retorno:
[ { "id": 1, "valor": "400.00", "descricao": "Preparação estética", "nome": "Tanatopraxia" } ]
GET /servico/:id
Buscar serviço por ID

Retorna um serviço específico através do ID.

Parâmetro:
  • ID do serviço.
Restrição:
  • O serviço deve existir.
Exemplo de retorno:
{ "id": 1, "valor": "400.00", "descricao": "Preparação estética", "nome": "Tanatopraxia" }
POST /servico
Adicionar serviço

Adiciona um novo serviço ao sistema.

Campos obrigatórios:
  • nome
  • valor
Campo opcional:
  • descricao
Restrições:
  • Nome não pode estar vazio.
  • Não pode existir outro serviço com o mesmo nome.
  • Valor deve ser maior que 0.
  • Valor deve ser numérico.
Exemplo de retorno:
{ "msg": "Serviço adicionado", "data": { "id": 5, "valor": "400.00", "descricao": "Preparação estética", "nome": "Tanatopraxia" } }
PUT /servico/:id
Editar serviço

Altera os dados de um serviço existente.

Campos obrigatórios:
  • nome
  • valor
Campo opcional:
  • descricao
Restrições:
  • Nome não pode estar vazio.
  • Não pode existir outro serviço com o mesmo nome.
  • Valor deve ser maior que 0.
  • Valor deve ser numérico.
Exemplo de retorno:
{ "msg": "Serviço editado", "data": { "id": 1, "valor": "500.00", "descricao": "Preparação completa", "nome": "Tanatopraxia Premium" } }
DELETE /servico/:id
Deletar serviço

Remove um serviço através do ID.

Restrição:
  • O serviço deve existir.
Exemplo de retorno:
{ "msg": "Serviço deletado" }

Clientes

Rotas responsáveis pelo gerenciamento dos clientes.

GET /cliente
Listar clientes

Retorna todos os clientes cadastrados.

Parâmetros:

Não possui.

Exemplo de retorno:
[ { "cpf": "12345678901", "nome_primeiro": "João", "nome_sobrenome": "Silva", "endereco_cep": "13560000", "endereco_rua": "Rua das Flores", "endereco_cidade": "São Carlos", "endereco_bairro": "Centro", "endereco_numero": 120, "contato_email": "joao.silva@email.com", "contato_telefone": "16999990001", "data_nascimento": "1985-03-15" } ]
GET /cliente/:cpf
Buscar cliente por CPF

Retorna um cliente específico através do CPF.

Parâmetro:
  • CPF do cliente.
Restrições:
  • O cliente deve existir.
  • O CPF deve possuir 11 números.
Exemplo de retorno:
{ "cpf": "12345678901", "nome_primeiro": "João", "nome_sobrenome": "Silva", "endereco_cep": "13560000", "endereco_rua": "Rua das Flores", "endereco_cidade": "São Carlos", "endereco_bairro": "Centro", "endereco_numero": 120, "contato_email": "joao.silva@email.com", "contato_telefone": "16999990001", "data_nascimento": "1985-03-15" }
POST /cliente
Adicionar cliente

Adiciona um novo cliente ao sistema.

Campos obrigatórios:
  • cpf
  • nome_primeiro
  • nome_sobrenome
  • contato_email
  • contato_telefone
Campos opcionais:
  • endereco_CEP
  • endereco_rua
  • endereco_cidade
  • endereco_bairro
  • endereco_numero
  • data_nascimento
Restrições:
  • CPF deve possuir 11 números.
  • CPF não pode estar cadastrado.
  • Telefone deve possuir 10 ou 11 números.
  • Data de nascimento deve ser igual ou posterior a 01/01/1900.
Exemplo de retorno:
{ "msg": "Cliente adicionado", "data": { "cpf": "11111111111", "nome_primeiro": "Ana", "nome_sobrenome": "Teste", "endereco_cep": "13560000", "endereco_rua": "Rua das Flores", "endereco_cidade": "São Carlos", "endereco_bairro": "Centro", "endereco_numero": 100, "contato_email": "ana.teste@email.com", "contato_telefone": "16999999999", "data_nascimento": "2008-05-10" } }

Operações Exclusivas

GET /cliente/funerais/:cpf
Buscar funerais de um cliente

Busca todos os funerais associados a determinado cliente através do CPF.

Retorna:
  • Nome do cliente.
  • Lista de funerais associados.
  • Nome do falecido.
  • Data e local do funeral.
  • Duração e pagamento.
Restrições:
  • O cliente deve existir.
  • O cliente deve possuir funerais associados.
Exemplo de retorno:
{ "msg": "Funerais encontrados com sucesso!", "cliente": "João Silva", "funerais": [ { "id": 1, "nome_falecido": "José da Silva", "data_evento": "2026-09-10", "local": "Cemitério Nossa Senhora do Carmo", "duracao": 4, "pagamento": "2500.00" } ] }
GET /cliente/servicos/:id
Buscar serviços de um funeral

Busca todos os serviços associados a determinado funeral através do ID.

Retorna:
  • Nome do falecido.
  • Lista de serviços.
  • Nome do serviço.
  • Descrição.
  • Valor.
Restrições:
  • ID do funeral deve ser válido.
  • O funeral deve existir.
  • O funeral deve possuir serviços associados.
Exemplo de retorno:
{ "msg": "Serviços encontrados com sucesso!", "funeral": "José da Silva", "servicos": [ { "id": 1, "nome": "Tanatopraxia", "descricao": "Preparação e conservação do corpo para o velório.", "valor": "500.00" }, { "id": 4, "nome": "Urna funerária", "descricao": "Fornecimento de urna funerária para o sepultamento.", "valor": "1500.00" }, { "id": 5, "nome": "Ornamentação", "descricao": "Decoração e ornamentação do ambiente do velório.", "valor": "400.00" }, { "id": 7, "nome": "Sala de velório", "descricao": "Locação da sala para realização do velório.", "valor": "350.00" } ] }
GET /servico/valor-total/:id
Calcular valor total do funeral

Mostra os dados do funeral e calcula o valor total dos serviços contratados.

Retorna:
  • Nome do falecido.
  • Nome do contratante.
  • Lista de serviços.
  • Valor total.
Restrições:
  • ID deve ser válido.
  • Funeral deve existir.
  • Deve possuir serviços associados.
Exemplo de retorno:
{ "msg": "Valor total calculado com sucesso!", "nome_falecido": "João da Silva", "contratante": "Maria Oliveira", "servicos": [ { "nome": "Velório", "valor": "500.00" }, { "nome": "Transporte", "valor": "300.00" } ], "valor_total": "800.00" }
GET /servico/clientes/:nome
Buscar clientes por serviço

Busca os clientes que contrataram determinado serviço.

Retorna:
  • Nome do cliente.
  • Data de nascimento.
  • Email.
  • Telefone.
Restrição:
  • O serviço deve existir.
Exemplo de retorno:
{ "servico": "Velório", "clientes": [ { "nome": "Maria Oliveira", "data_nascimento": "1980-05-10", "email": "maria@email.com", "telefone": "16999999999" }, { "nome": "Carlos Souza", "data_nascimento": "1975-08-22", "email": "carlos@email.com", "telefone": "16988888888" } ] }
GET /funeral/servicos/mais-utilizados
Buscar serviços mais utilizados

Retorna os serviços utilizados nos funerais, ordenados pela quantidade de vezes em que foram contratados.

Parâmetros:

Não possui.

Retorna:
  • ID do serviço.
  • Nome do serviço.
  • Descrição.
  • Valor.
  • Quantidade de vezes em que foi utilizado.
Exemplo de retorno:
{ "msg": "Serviços mais utilizados encontrados com sucesso!", "data": [ { "id": 1, "nome": "Tanatopraxia", "descricao": "Preparação e conservação do corpo para o velório.", "valor": "500.00", "quantidade_utilizada": "6" } ] }
GET /funeral/periodo
Buscar funerais por período

Busca os funerais realizados entre duas datas informadas.

Parâmetros de consulta:
  • inicio - data inicial.
  • fim - data final.
Exemplo de requisição:
/funeral/periodo?inicio=2026-09-10&fim=2026-09-20
Restrições:
  • A data inicial deve ser informada.
  • A data final deve ser informada.
  • A data inicial não pode ser maior que a data final.
Exemplo de retorno:
{ "msg": "Funerais encontrados com sucesso!", "data": [ { "id": 1, "nome_falecido": "José da Silva", "data_evento": "2026-09-10", "local": "Cemitério Nossa Senhora do Carmo", "pagamento": true, "nome_primeiro": "João", "nome_sobrenome": "Silva" } ] }
